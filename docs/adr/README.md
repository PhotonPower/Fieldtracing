# Architecture Decision Records

Neue Entscheidungen bekommen die nächste Nummer. Bestehende ADRs werden nicht umgeschrieben,
sondern durch ein neues ADR mit Status „ersetzt durch“ abgelöst; Präzisierungen kommen als
datierter Nachtrag ans Ende (wie in Raytatouille).

| Nr. | Titel | Status |
| --- | --- | --- |

| [0002](0002.md) | Konventionen von Raytatouille | angenommen |
| [0003](0003.md) | Hybride Rückgabe und Interpolationsregel | angenommen |

# ADR NNNN: Titel
